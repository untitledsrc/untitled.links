2

Файл ответа

Сгенерируйте свой autounattend.xml или скачайте готовый: он автоматизирует часть шагов установки. Чтобы после установки нужные файлы оказались на рабочем столе, создайте на флешке папку extras и добавьте в файл ответа скрипт ниже: он скопирует её содержимое на общий рабочий стол.

autounattend.xml
✕
Файл ответа для образа windows
Генерировать Скачать
PowerShell 
$dest = 'C:\Users\Public\Desktop'
New-Item -ItemType Directory -Path $dest -Force | Out-Null

$src = Get-PSDrive -PSProvider FileSystem |
    Where-Object {
        $root = $_.Root
        (Test-Path (Join-Path $root 'extras')) -and
        (
            (Test-Path (Join-Path $root 'setup.exe')) -or
            (Test-Path (Join-Path $root 'sources\boot.wim'))
        )
    } |
    Select-Object -First 1

if ($src) {
    $extras = Join-Path $src.Root 'extras'
    Copy-Item "$extras\*" $dest -Recurse -Force
} else {
    Write-Host 'Установочная флешка с папкой extras не найдена.'
}

Скрипт ищет установочную флешку по папке extras и файлу setup.exe или sources\boot.wim.

Rufus

Запишите образ на флешку: Rufus сделает её загрузочной. Затем положите в корень флешки autounattend.xml и папку extras: её содержимое попадёт на рабочий стол.
